# Study Planner App

A simple Flutter application designed to help students manage their study subjects and track their progress.

---

## Features
- Add new subjects
- Track study progress (completed hours / total hours)
- Progress bar for each subject
- Delete subjects
- Clean and simple user interface

---

## Tech Stack
- Flutter
- Provider (State Management)
- Firebase Firestore (optional / future use)

---
